## What's inside

- **Studio** (`/studio`): turn a short brief into one complete, self-contained HTML design. It renders live as it streams, you revise it by chatting, every revision is kept as a version, and you can download the result.
- **TriumpCode Web** (`/code`): an AI coding agent that builds multi-file web projects. Chat on the left, live preview on the right, zip download.
- **TriumpCode CLI** (`cli/`): the same agent in your terminal. It reads, searches and edits files and runs commands in your folder, and it asks before every write and every command.
- **Sign in three ways**, all linked to one account:
  - **Wallet**: MetaMask, Rabby or Coinbase Wallet. The user signs an EIP-4361 message (no gas) and the server verifies the signature with no library.
  - **X**: OAuth 2.0 with PKCE.
  - **Email / Google**: pick a Google account signed in to the browser (optional, needs `TRIUMP_GOOGLE_CLIENT_ID` in `public/config.js`) or type any email, then confirm with a one-time code. Disposable and fake addresses are rejected.
- **Plans**: a free daily quota for everyone who signs in. Token holders on Robinhood Chain get 3 months unlimited, checked on-chain.

## Stack

- **Server:** Node 24, running TypeScript directly. There is no build step and one dependency, [`@anthropic-ai/sdk`](https://www.npmjs.com/package/@anthropic-ai/sdk).
- **Frontend:** plain HTML, CSS and JS in `public/`.
- **Storage:** small JSON files in `data/`, created automatically.
- **AI:** Claude through the Anthropic API. The model is set by `STUDIO_MODEL` / `CODE_MODEL` and defaults to `claude-opus-5`.

## Quick start

```bash
git clone <this repo> triumpai && cd triumpai
npm install
cp .env.example .env        # add at least ANTHROPIC_API_KEY
npm run serve               # http://localhost:7474
```

Studio and TriumpCode need `ANTHROPIC_API_KEY`. Email sign-in needs the `SMTP_*` settings, and X sign-in needs `X_CLIENT_ID` / `X_CLIENT_SECRET`. Every variable is documented in [`.env.example`](.env.example). A feature whose settings are missing is switched off; the rest of the site keeps working.

## Project layout

```
public/          the website (HTML, CSS, JS, images)
  config.js      token contract address, buy links, chain settings: the one file to edit at launch
  made.js        the "Made with TRIUMP AI" gallery
src/server.ts    static files, sign-in (email / X / wallet), sessions
src/apps.ts      Studio, TriumpCode web + CLI API, plans & quota, sandboxed previews
src/evm.ts       keccak256 + secp256k1 signature recovery (no dependencies)
cli/             TriumpCode CLI, a zero-dependency Node package
seed/studio/     the gallery designs, copied into data/ on first start
deploy/          systemd unit, Caddy block, ship script
brand/           pixel logo in every size, X banner (banner/, source in banner.html)
```

## TriumpCode CLI

```bash
npm install -g https://triumpai.com/dl/triumpcode.tgz
triumpcode login            # opens the browser; approve the code
cd my-project && triumpcode
```

`npm run pack-cli` rebuilds `public/dl/triumpcode.tgz` from `cli/`. To use another server, run `triumpcode --server https://your-domain login`.

## Security notes

- Previews of AI-generated code are served with a `Content-Security-Policy: sandbox` header, so they run on an isolated origin and can't read the site's login cookie.
- The Anthropic key, SMTP password and X secret live only in `.env` on the server. They are never sent to the browser.
- Wallet sign-in accepts only a signature over a single-use nonce that expires after 5 minutes.
